# 📊 多模态交互压力数据分析系统

一款面向办公用户的桌面端工具，通过分析用户与电脑的多模态交互行为，自动评估工作压力状态，提供压力监测、趋势分析与健康干预建议。**所有功能完全离线运行，数据仅在本地存储，保障用户隐私。**

---

### 文件结构

| 文件 | 说明 |
|------|------|
| `main.py` | 主程序入口，界面布局与交互逻辑 |
| `config.py` | 全局配置、常量定义、情感词典 |
| `collector.py` | 多模态数据采集（键盘/鼠标/窗口/文本） |
| `analyzer.py` | 压力分析引擎（归一化/融合/分级/来源识别） |
| `storage.py` | 数据存储（SQLite/Excel导出/备份） |
| `visualizer.py` | 图表可视化（Matplotlib嵌入Tkinter） |
| `alerts.py` | 预警干预（持续高压检测/弹窗提醒） |
| `requirements.txt` | Python依赖包列表 |

### 压力评估流程

1. **数据采集**：后台静默采集键盘输入节奏、鼠标点击/移动/滚动频率、窗口切换频率
2. **特征归一化**：将各维度原始数据映射到 0-1 范围
3. **文本情绪分析**：基于本地情感词典分析输入文本情绪（仅本地处理）
4. **加权融合**：按配置权重融合多维特征，计算 0-100 综合压力分数
5. **等级分类**：将分数映射为 4 级 —— 低压力 / 正常 / 中等压力 / 高压力
6. **来源识别**：分析各维度贡献，识别压力来源（任务过载/情绪负面/节奏过快等）
7. **预警干预**：连续高压超过阈值时弹窗提醒，给出个性化放松建议

### 技术栈

- **桌面框架**: Python Tkinter/ttk
- **数据处理**: Pandas
- **可视化**: Matplotlib（中文适配）
- **数据存储**: SQLite
- **输入监听**: pynput
- **系统信息**: psutil

## 安装与运行

### 环境要求

- Python 3.8+
- 操作系统：Windows / macOS / Linux

### 安装步骤

```bash
# 1. 克隆或下载项目
git clone <repo-url>
cd 111

# 2. 安装依赖
pip install -r requirements.txt

# 3. 运行程序
python main.py
```

### 平台说明

- **Windows**: 开箱即用，pynput 完全支持
- **macOS**: 需在「系统设置 → 隐私与安全 → 辅助功能」中授权 Terminal/Python
- **Linux**: 需要 X11 环境。如需中文显示，安装字体：`sudo apt install fonts-noto-cjk`
- **无图形环境**: 程序自动切换为模拟数据模式，可用于开发测试

## 使用说明

### 快速开始

1. 运行 `python main.py` 启动程序
2. 点击右上角 **「▶ 开始采集」** 开始监测
3. 程序将在后台静默采集数据，每分钟自动分析一次
4. 实时仪表盘展示当前压力状态、趋势图和贡献占比
5. 切换到 **「历史记录」** 查看日/周/月趋势和详细数据
6. 在 **「系统设置」** 中自定义预警规则和管理数据

### 功能模块

| 模块 | 说明 |
|------|------|
| 📊 实时仪表盘 | 实时压力状态、仪表盘、趋势图、模态贡献占比、压力来源 |
| 📅 历史记录 | 日/周/月趋势、每日汇总柱状图、详细数据表格、Excel导出 |
| ⚙️ 系统设置 | 预警阈值调整、数据导出/备份/清除、关于信息 |

### 压力等级

| 等级 | 分数范围 | 说明 |
|------|---------|------|
| 😊 低压力 | 0-25 | 放松状态，工作节奏平稳 |
| 🙂 正常 | 25-50 | 正常工作状态，压力适中 |
| 😐 中等压力 | 50-75 | 压力有所上升，建议适当休息 |
| 😰 高压力 | 75-100 | 压力较高，建议立即休息 |

### 隐私保护

- ✅ 所有数据仅在本地处理和存储
- ✅ 不连接任何网络，不调用外部API
- ✅ 仅采集行为统计特征（频率/速度），不记录具体按键内容
- ✅ 文本情绪分析完全基于本地词典，输入内容不外传
- ✅ 支持随时清除所有历史数据

### 可穿戴设备扩展

系统预留了可穿戴设备数据接入接口，支持心率（BPM）和皮电响应（GSR）数据：

```python
# 开发者可通过以下方式传入生理数据
collector.update_wearable_data(heart_rate=85, gsr=3.2)
```

## 开发说明

### 调试模式

在 `config.py` 中设置 `DEBUG = True` 可开启详细日志输出，方便开发调试。

### 模拟数据模式

当 pynput 不可用时（如服务器环境），系统自动使用模拟数据模式，可正常运行所有界面功能。

### 自定义权重

在 `config.py` 的 `FEATURE_WEIGHTS` 中调整各特征的权重分配，影响压力评估结果。

### 扩展情感词典

在 `config.py` 的 `NEGATIVE_WORDS` 和 `POSITIVE_WORDS` 中添加更多关键词，提升文本情绪分析精度。
