# 多模态交互压力数据分析系统

> Multimodal Interaction Stress Analysis System

一款面向办公用户的桌面端工具，能够在本地采集用户与电脑交互的多模态数据，自动分析用户的工作压力状态，提供压力监测、趋势分析与健康干预建议。所有功能完全离线可用，保障用户隐私。

---

## 系统设计说明

### 整体架构

```
┌─────────────────────────────────────────────────┐
│              main.py (Tkinter GUI)              │
│         仪表盘 │ 历史记录 │ 设置管理            │
├──────────┬──────────┬──────────┬────────────────┤
│collector │ analyzer │visualizer│    alerts       │
│数据采集  │ 压力分析 │ 可视化   │   预警干预      │
├──────────┴──────────┴──────────┴────────────────┤
│              storage.py (SQLite + 加密)          │
├─────────────────────────────────────────────────┤
│              config.py (全局配置)                │
└─────────────────────────────────────────────────┘
```

### 模块说明

| 模块 | 文件 | 功能 |
|------|------|------|
| 全局配置 | `config.py` | 压力等级定义、阈值、路径、日志等全局常量 |
| 数据采集 | `collector.py` | 后台静默采集键盘/鼠标/窗口切换等行为数据 |
| 压力分析 | `analyzer.py` | 多模态特征融合引擎，4级压力分类，压力来源识别 |
| 数据存储 | `storage.py` | SQLite本地存储，可选Fernet加密，数据导出/备份 |
| 可视化 | `visualizer.py` | Matplotlib图表组件（仪表盘/趋势图/雷达图/饼图） |
| 预警干预 | `alerts.py` | 高压力检测、温和提醒、放松建议 |
| 主程序 | `main.py` | Tkinter桌面应用，集成所有模块 |

### 压力分析模型

系统基于以下多模态特征进行综合压力评估：

- **键盘节奏 (20%)** — 按键间隔的标准差，反映输入规律性
- **键盘速度 (15%)** — 与个人基线的偏离程度
- **鼠标活动 (15%)** — 点击频率和移动速度
- **滚动强度 (10%)** — 页面滚动操作频率
- **窗口切换 (15%)** — 应用切换频率
- **文本情绪 (10%)** — 输入停顿模式分析
- **输入停顿 (10%)** — 长停顿的频率和时长
- **可穿戴设备 (5%)** — 预留接口

压力分为4个等级：
- 🟢 **低压力** (0-25分)
- 🔵 **正常** (25-50分)
- 🟠 **中等压力** (50-75分)
- 🔴 **高压力** (75-100分)

## 快速开始

### 环境要求

- Python 3.8+
- 操作系统: Windows / macOS / Linux

### 安装依赖

```bash
pip install -r requirements.txt
```

### 运行系统

```bash
python main.py
```

### 使用说明

1. **启动采集** — 点击顶部工具栏的「开始采集」按钮
2. **查看实时状态** — 在「实时仪表盘」页面查看当前压力评分、趋势和各模态贡献
3. **查看历史** — 切换到「历史记录」页面，选择时间范围查看趋势
4. **导出报告** — 在历史记录页面点击「导出Excel」
5. **调整设置** — 在「设置」页面自定义预警规则和管理数据

> **注意**: 如果系统检测到 `pynput` 无法正常工作（如无图形界面环境），会自动切换到模拟数据模式进行演示。

### 数据隐私

- ✅ 所有数据仅存储在本地 (`~/.stressanalyzer/`)
- ✅ 支持可选的Fernet对称加密
- ✅ 不依赖任何外部API，完全离线运行
- ✅ 随时可备份、导出或清除数据

## 技术栈

- **桌面框架**: Python Tkinter/ttk
- **数据处理**: Pandas + NumPy
- **可视化**: Matplotlib（适配中文显示）
- **数据存储**: SQLite3（WAL模式）
- **数据加密**: cryptography (Fernet)
- **行为采集**: pynput（键盘/鼠标监听）
- **情感分析**: SnowNLP（可选，中文离线）
